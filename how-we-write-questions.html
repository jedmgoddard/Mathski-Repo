How we write our questions

Last updated 22 October 2026

Every question in the Mathski Question Bank is original, written for a specific IB Maths course and topic, and checked several ways before it is published.

1. Written for the syllabus

Each question is written for one course (AA or AI), one of the five topics, and a named subtopic. HL-only questions cover the HL extension content. Long questions follow the style of Section B (AA) and Paper 2 (AI).

2. Original

Questions are written from scratch in the style of IB exams. We don't copy or lightly edit past-paper questions. Each set is compared against a list of existing questions to catch anything that is too close to a published one.

3. Labelled for difficulty, per course

Each question is labelled Easy, Medium or Hard. The same question can carry a different label at SL and HL, because what is hard for one course can be routine for another.

4. Worked solutions for learning

Solutions are written for a student to learn from, not as brief markscheme lines. Each one starts with the key idea, then shows every step and gives the final answer clearly.

5. Every answer checked independently

Each answer is recalculated by a separate checking script, using computer algebra and numerical methods, that does not share any working with the solution. A question is only published when the two agree.

6. Checked on screen

Every question and solution is rendered and checked on desktop and phone sizes, including all diagrams and mathematical notation.

7. Reviewed by a teacher

Finally, each set is reviewed by an experienced IB teacher before release.

Spotted a mistake? Email mathskiadmin@gmail.com with the course, topic and question number and we'll fix it.
